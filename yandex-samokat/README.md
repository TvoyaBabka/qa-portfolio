# Яндекс Самокат — дипломный проект

Комплексное тестирование учебного сервиса аренды самокатов: веб-приложения для заказчиков, Android-приложения для курьеров и API.

## Моя работа

Анализировала требования и макеты, составляла чек-листы и тест-кейсы, подбирала тестовые данные и выполняла проверки. Найденные дефекты оформляла в баг-репорты. Дополнительно проверяла функциональность по требованиям и макетам вне подготовленной тестовой документации.

## Что проверяла

| Область | Проверки |
|---|---|
| Web | Валидация полей заказа, данные и статусы заказа, отмена, просрочка, отображение интерфейса в двух браузерах и двух разрешениях |
| Android | Уведомления, переход в приложение из уведомления, состояния приложения и поведение при отсутствии сети |
| API | Создание, авторизация и удаление курьера, получение заказа по номеру отслеживания, позитивные и негативные запросы |
| База данных | Сохранение данных курьера и проверка записей после удаления |

## Инструменты и окружения

Postman, Android Studio, SQL, Google Chrome, Яндекс Браузер.

- Web: Windows 11; Яндекс Браузер 26.4.5.646 и Google Chrome 149.0.7827.201; разрешения 1920×1080 и 1280×720.
- Mobile: Яндекс Самокат 2.0, эмулятор Android 9.0 в Android Studio.
