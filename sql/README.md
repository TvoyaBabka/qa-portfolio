# SQL — база стартапов и инвестиций

Учебный проект по работе с реляционной базой данных о компаниях, сотрудниках, венчурных фондах, инвестициях и сделках приобретения компаний.

## Моя работа

Изучала структуру базы и писала SQL-запросы для получения и анализа данных: фильтровала записи, подсчитывала количество компаний и суммы инвестиций, группировала результаты и объединяла данные таблиц.

## Что представлено

Восемь выполненных заданий с моими запросами:

| № | Задача | SQL |
|---|---|---|
| 1 | Подсчёт закрывшихся компаний | COUNT, WHERE |
| 2 | Привлечённые средства новостных компаний США | WHERE, AND, ORDER BY |
| 3 | Поиск аккаунтов по началу названия | LIKE |
| 4 | Поиск по подстроке аккаунта и началу фамилии | LIKE, AND |
| 5 | Сумма инвестиций по странам | SUM, GROUP BY, ORDER BY |
| 6 | Сотрудники и их учебные заведения | LEFT JOIN, псевдонимы таблиц |
| 7 | Сумма сделок за наличные за период | SUM, BETWEEN |
| 8 | Статистика инвестиционной активности фондов по странам | MIN, MAX, AVG, GROUP BY, HAVING, LIMIT |
