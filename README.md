# София Тукаева — QA-портфолио

Практические работы по ручному тестированию веб-приложений, мобильных приложений, API и баз данных.

## Проекты

| Проект | Области тестирования | Документация |
|---|---|---|
| [Яндекс Самокат](yandex-samokat/README.md) | Web, Android, API, SQL | Чек-листы, тест-дизайн, тест-кейсы и баг-репорты |

| [Яндекс Прилавок](yandex-prilavok/README.md) | API, JSON, XML | Чек-лист, баг-репорты и сохранённая документация API |
| [Яндекс Метро](yandex-metro/README.md) | Android, функциональное и регрессионное тестирование | Чек-листы, баг-репорты и требования |
| [Яндекс Маршруты](yandex-routes/README.md) | Web, интерфейс и логика бронирования | Чек-листы, тест-кейсы, баг-репорты и ссылка на дизайн |
| [База стартапов и инвестиций](sql/README.md) | SQL, фильтрация, агрегация и объединение таблиц | 8 заданий с запросами, описание базы и ER-диаграмма |
| [Mesto](mesto/README.md) | Web, регрессионное тестирование и ретест | Результаты выполнения тест-кейсов, баг-репорты и требования |

## Навыки, представленные в работах

- Анализ требований и макетов.
- Составление чек-листов и тест-кейсов.
- Подбор данных с использованием классов эквивалентности и граничных значений.
- Позитивное и негативное тестирование API в Postman.
- Проверка данных с помощью SQL.
- Оформление дефектов и результатов тестирования.

В портфолио представлены учебные проекты. Подробности моей работы и окружений указаны в описании каждого проекта.
