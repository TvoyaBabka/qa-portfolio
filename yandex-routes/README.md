# Яндекс Маршруты — тестирование веб-приложения

Учебный проект по тестированию функциональности каршеринга в веб-сервисе Яндекс Маршруты.

## Моя работа

Составляла чек-листы и тест-кейсы, выполняла проверки интерфейса и функциональности формы бронирования, оформляла найденные несоответствия в баг-репорты.

## Что проверяла

- Вёрстку формы бронирования, тарифы и элементы интерфейса.
- Окна «Способ оплаты» и «Добавление карты».
- Логику кнопки «Забронировать» при разных сочетаниях заполненных полей: адресов, водительских прав и банковской карты.
- Отображение интерфейса в двух браузерах и разрешениях экрана.

## Окружения

В документации указаны Firefox с разрешением 1920×1080 и Яндекс Браузер с разрешением 800×600. Окружение выполнения каждой проверки приведено в таблице.
