# Яндекс Прилавок — тестирование API

Учебный проект по тестированию API сервиса заказа продуктов.

## Моя работа

Анализировала требования, разрабатывала чек-лист, выполняла проверки в Postman и оформляла выявленные несоответствия в баг-репорты.

## Что проверяла

- Добавление товаров в корзину: идентификаторы товаров, количество и повторное добавление.
- Добавление товаров в наборы: корректные и некорректные данные, состав запроса и ответы сервера.
- Расчёт курьерской доставки: время доставки, количество и вес товаров, стоимость и возможность доставки.
- HTTP-статусы и содержимое ответов, включая JSON и XML.

## Инструменты

Postman. Работа с запросами и ответами в форматах JSON и XML.
