# Mesto — регрессионное тестирование и ретест

Учебный проект по тестированию веб-приложения для публикации фотографий мест.

## Моя работа

Проводила регрессионное тестирование по готовым тест-кейсам, фиксировала результаты, выявляла дефекты и составляла баг-репорты. Выполняла ретест багов, найденных другими тестировщиками, на тестовом стенде и отмечала результаты проверки исправлений.

## Области проверки

- Редактирование профиля: имя и занятие, сохранение данных, валидация полей.
- Работа с карточками мест: добавление, удаление и просмотр фотографий.
- Элементы интерфейса и поведение окон.
